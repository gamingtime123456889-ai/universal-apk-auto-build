=== HOW TO BUILD APK FREE USING GOOGLE COLAB ===

1. Open Google Colab in your browser: https://colab.research.google.com/
2. Create a new notebook.
3. Paste and run the following code blocks one by one:

--- BLOCK 1 (Install Dependencies) ---
!sudo apt update && !sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev libreadline-dev libsqlite3-dev libssl-dev libffi-dev
!pip install --upgrade buildozer cython

--- BLOCK 2 (Build APK) ---
!buildozer -v android debug

4. Upload your project files (main.py, buildozer.spec) to Colab file explorer before running block 2!
